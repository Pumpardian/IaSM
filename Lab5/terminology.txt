Классы:
s_net (S-сеть / машина состояний): У переходов ровно один вход и один выход.

t_net (T-сеть / размеченный граф): У позиции ровно один вход и один выход.

free_choice (свободного выбора): Если два перехода имеют общую входную позицию (конфликтуют за ресурс), то множества всех их входных позиций должны быть абсолютно одинаковыми.

restricted_free_choice: Если позиция имеет несколько выходов (ветвление / выбор), то эти выходы не могут быть входами для каких-либо других позиций.
 И наоборот: если переход имеет несколько входов (синхронизация), у этих позиций не может быть других альтернативных выходов.

asymmetric_choice (асимметричного выбора): Если два перехода делят входную позицию, то входные множества одного являются подмножеством другого.

Структурные свойства:

safe (безопасная): k-ограниченая.

консервативность: Если у каждого перехода число входных дуг равно числу выходных (с учётом весов), то сеть консервативна.

reversible (обратимость): В графе из каждой вершины есть путь назад к начальной маркировке.

deadlock (тупик): Маркировка, в которой нет активных переходов.

pure (чистая): В сети нет позиции, которая одновременно является входной и выходной для одного и того же перехода.

homogeneous (однородная): Все дуги имеют вес 1 (нет кратных дуг).

isolated_elements (изолированные элементы): В сети нет «висячих» вершин, не соединенных ни с чем.

weakly_connected (слабо связная): Если убрать направление дуг, граф остается связным (нет отдельно стоящих «островов»).

strongly_connected (сильно связная): Из любой вершины можно добраться до любой другой по направлению дуг. (нет тупиков или начальных вершин без входа).

output_nonbranching (неветвящийся выход): Каждая позиция в сети имеет не более одного исходящего перехода.


Поведенческие свойства:

simply_live (просто живая): Каждый переход может сработать хотя бы один раз из начальной маркировки.

strongly_live (сильно живая): Каждый переход может сработать из любой достижимой маркировки (нет тупиков или блокировок).

weakly_live (слабо живая): В сети есть хотя бы один переход, который не может сработать никогда (мертвый переход).

persistent (устойчивая): Срабатывание одного перехода не отключает (блокирует) другой переход.

backwards_persistent (обратно-устойчивая): Если переход сработал, то он не «включил» другие переходы, которые до этого были неактивны.

conflict_free (бесконфликтная): В сети нет конфликтов (переходы не конкурируют за фишки в общих входных позициях).

Behaviourally Conflict Free (Поведенчески бесконфликтная сеть)
bcf: Если в каком-либо достижимом состоянии сети (маркировке) одновременно активированы два разных перехода t₁ и t₂, то срабатывание одного
 из них не должно отнимать фишки у другого. То есть они могут сработать параллельно или в любом порядке, не мешая друг другу.

Binary Conflict Free (Бинарно бесконфликтная сеть)
bicf: В сети нет пар переходов, которые находятся в состоянии чистого бинарного выбора (когда одна фишка разделяется строго между двумя
 альтернативными путями, полностью блокируя один из них при выборе другого).
